# YouthPulse – Faith‑Powered Mini‑Games & Badges
YouthPulse is a static, ultra‑light web hub where Kinshasa’s Christian youth play 2‑3 minute faith‑games, earn badges, share memes, and watch local video testimonies—all loading in under 2 seconds on 2 Mbps.
